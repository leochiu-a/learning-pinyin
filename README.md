# 拼音步道

給會注音的台灣人學漢語拼音的網站。用你已經熟悉的注音當橋梁，一步一步學會「看得懂、打得出」拼音。

**線上使用：** <https://leochiu-a.github.io/learning-pinyin/>

## 功能

- **12 步課程**：從單韻母 ㄚㄛㄜㄧㄨㄩ 開始，依序學聲母、聲調、ㄐㄑㄒ、翹舌音、複韻母、鼻音韻母、ㄧㄨㄩ 開頭的韻母，最後打整個詞。每一步都有注音對拼音的對照卡，以及「台灣人最容易打錯」的提醒。
- **打字練習**：看漢字和注音打出拼音。打錯時會馬上說明是哪條規則，例如「ㄧㄡ 接在聲母後面縮寫成 iu」，鍵盤也會亮出下一個該按的鍵。每一步第一次就打對 80% 才會開下一步。
- **打文章**：一個字一個字打出整段文字的拼音，打的拼音會留在字的下方。即時顯示每分鐘字數和正確率，並記下每篇的最佳成績。文章頁每天輪替 3 篇「今天的短文」。
- **針對錯字練習**：打完文章後，練習打錯的字，以及錯在同一處的其他字。錯在聲母就練同聲母的字，錯在聲調就練同聲調的字，其他就練同一條拼寫規則的字。錯字要連續打對兩次才算過。
- **注音拼音對照表**：37 個注音符號、結合韻母和聲調的完整對照，容易打錯的格子會特別標出來。

一些設計上的選擇：

- **聲調預設不用打**：真正的拼音輸入法只打字母再選字，所以打聲調是可以自己打開的選項。打開後在音節後面加數字 1–5，輕聲打 5 或不打都可以。只有「四聲與輕聲」那一步一定要打。
- **台灣讀音**：拼音照台灣的讀法，以教育部《國語辭典》（萌典）為準，例如星期 xīngqí、垃圾 lèsè、頭髮 tóufǎ。
- **ü 打 v**：和一般拼音輸入法一樣。
- **進度只存在瀏覽器**：學習進度和成績存在瀏覽器的 localStorage，不需要註冊。換電腦或清除瀏覽器資料就會重新開始。

## 開發

需要 Node.js 24 和 pnpm。

```bash
pnpm install
pnpm dev
```

| 指令                          | 用途                           |
| ----------------------------- | ------------------------------ |
| `pnpm dev`                    | 開發伺服器                     |
| `pnpm build`                  | 型別檢查並打包到 `dist/`       |
| `pnpm test`                   | 執行單元測試（Vitest）         |
| `pnpm lint`                   | 用 oxlint 檢查，有警告也算失敗 |
| `pnpm fmt` / `pnpm fmt:check` | 用 oxfmt 格式化／檢查格式      |

commit 時 husky 會用 lint-staged 對 staged 的檔案跑 oxlint 和 oxfmt。

技術：React 19、React Router、TypeScript、Vite。

### 專案結構

```text
src/
  data/        課程、文章、對照表的內容
  lib/         拼音／注音轉換、答案比對、出題與針對練習的邏輯（純函式，附測試）
  hooks/       打一個字的共用輸入邏輯 useSyllableTyping
  components/  畫面元件：步道、練習、鍵盤、提示……
  pages/       各路由的頁面：課程、打文章
```

### 新增文章

**用 skill 自動補一批（建議）**：在這個 repo 裡開 Claude Code，輸入 `/add-articles`。它會從維基百科首頁、新聞找題材，改寫成原創短文，查萌典標上台灣讀音，跑完檢查後 commit 並推上去。過一陣子跑一次，文章庫就會一直變大。

**手動加**：

在 `src/data/articles.ts` 加一筆資料，`pinyin` 依序寫出每個漢字的數字標調拼音，用空白分隔，標點不用寫：

```ts
{
  id: 'night-market',
  title: '逛夜市',
  level: '入門',
  topic: '生活',
  added: '2026-10-18',
  text: '我們去夜市吧！',
  pinyin: 'wo3 men5 qu4 ye4 shi4 ba5',
},
```

注音會從拼音自動轉出來。`pnpm test` 會檢查每個漢字都剛好有一個正確的拼音，字數對不上或拼音寫錯時測試不會過。

## 部署

推到 `main` 後，GitHub Actions 會依序檢查格式、lint、測試、打包，然後部署到 GitHub Pages。任何一步失敗就不會部署。

GitHub Pages 不支援單頁應用的網址，所以打包時會把 `index.html` 複製成 `404.html`。直接打開 `/articles/poem` 這類網址時畫面正常，但伺服器回傳的狀態碼是 404。
